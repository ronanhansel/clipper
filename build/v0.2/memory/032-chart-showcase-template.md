# Chart Showcase Template

## Summary

- Added `prt_chart_showcase.ts` as a sample composition that demonstrates many `defineChart` chart types in one template.
- Registered the showcase in `src/sampleProject.ts` and `clipper/projects/prj_v01_sample/project.json`.
- The template is intended as a visual API catalog: authors can copy one `defineChart` block and then animate generated ids later.

## Included Charts

- Line, area, bar, grouped bar, stacked bar, scatter/bubble, donut, radar, gauge, heatmap, waterfall, and radial bar.
